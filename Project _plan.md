# Fresh Cut Property Preservation

## Vision

Build an AI-powered property preservation platform that guides field technicians through every work order, automatically requests required photos, verifies job completion, and generates client-ready reports.

---

# Phase 1 - Minimum Viable Product (MVP)

### Manager Dashboard
- Login
- Create Work Order
- Upload Work Order PDF
- Assign Employee
- View Job Progress
- Review Photos
- Complete Report

### Employee App
- Secure Login
- View Assigned Jobs
- GPS Navigation
- Step-by-Step Task List
- Required Photo Capture
- GPS & Timestamp on Photos
- Voice Notes
- Offline Mode

### AI Features
- Read uploaded work orders
- Create task checklist automatically
- Identify required photos
- Detect missing photos
- Detect blurry photos
- Generate completion report
